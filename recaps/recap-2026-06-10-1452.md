Re-diagnosis with symbols + console produced full root causes:
- **fal.ai abort**: `BlobResourceHandle` dtor → `~AsyncFileStream` →
  `callOnFileThread` → `std::call_once` → `WTF::Thread::create` →
  RELEASE_ASSERT (single-threaded build). **Fix** (WebKit tree, ledger):
  `#if defined(__EMSCRIPTEN__)` → `RunLoop::mainSingleton().dispatch()`
  (FIFO preserved, MEMFS I/O safe on main thread).
- Same-sweep audit of every `Thread::create` in WebCore:
  `callOnIDBSerializationThreadAndWait` (IDBBindingUtilities.cpp) would abort
  THEN semaphore-deadlock — **fixed inline** (static NeverDestroyed
  IDBSerializationContext, own small VM). GC-controller path is debug-only;
  audio/video/webrtc compiled out; workers already guarded; WebSQL +
  ServiceWorkers default off. Audit complete.
- **discord console revealed**: `Can't find variable: localStorage`,
  `null is not an object (evaluating 'a.contentWindow.document')` (iframes!),
  Workers unsupported (expected), `Can't find variable: WebAssembly`
  (CLoop, expected).
- **Root cause #11 (storage)**: `LocalStorageEnabled`/`SessionStorageEnabled`
  default **FALSE at the WebCore layer** (IDL-gated → ReferenceError, fatal
  to SPA bootstraps) AND EmptyStorageNamespaceProvider discards writes. New
  **src/embedder/BibStorage.h**: StorageMap-backed areas, per-origin, 5MB
  quota, Local/TransientLocal/Session namespaces; settings flipped in
  main.cpp; provider installed on PageConfiguration. In-memory lifetime
  (same policy as cookies).
- **Root cause #12 (subframes)**: `EmptyFrameLoaderClient::createFrame`
  returns nullptr → every iframe contentWindow null. Implemented
  `BibFrameLoaderClient::createFrame` (WebKitLegacy WebFrame.mm recipe:
  `LocalFrame::createSubframe` + `setSpecifiedName` + `init()` + page-null
  recheck) and `transitionToCommittedForNewPage` (WebKit2 recipe:
  `frame->createView()` on EVERY commit, carrying old size +
  canHaveScrollbars). Both finals relaxed in EmptyFrameLoaderClient.h
  (ledger). **main.cpp: Engine no longer caches LocalFrameView** — new
  `mainFrameView()` live lookup (a cached view goes stale → blank paint after
  first navigation); boot re-fetches after `init()` and the writer-load.
  Build fixes along the way: base class keeps `m_loader` private → own
  `WeakRef<FrameLoader> m_frameLoader`; `Frame::page()` inline lives in
  DocumentPage.h (WebKit inline-header pattern).

Verification: offscreen gate byte-identical (exactBlue=20000 redGlyph=1541);
